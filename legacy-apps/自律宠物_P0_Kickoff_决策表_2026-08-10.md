- 决策后由我做的事：创建目录骨架、`.gitignore`、初始 README。

### 2. 独立 Git 仓库

- **默认建议：** 在项目目录内 `git init` 独立仓库；首个 commit 前完成 `.gitignore`（排除 `.xcuserdata/`、`DerivedData/`、`*.xcuserstate`、`Pods/` 等）。
- 注意：现有 `/Users/USER/Documents/app/.git` 是混合仓库，不直接复用。
- 决策后由我做的事：初始化仓库 + 首次提交（仅工程骨架，不提交任何 Apple 凭据）。

### 3. Xcode 工程创建授权

- **默认建议：** 工程名 `自律宠物P0`（中性工程名，不含正式产品名——正式名称 P0 通过后才核验）；Xcode 工程文件直接建在项目根目录。
- 需用户单独授权创建工程（PRD §8.7-3）。
- 决策后由我做的事：创建四 Target 工程骨架（见下条）。

### 4. Bundle ID / App Group ID / Target 命名

- **默认建议（占位，最终前缀取决于你的域名/Team）：**
  - 主 App：`com.<你的域名>.petfocus`
  - Device Activity Monitor Extension：`com.<你的域名>.petfocus.monitor`
  - Shield Configuration Extension：`com.<你的域名>.petfocus.shieldconfig`
  - Shield Action Extension：`com.<你的域名>.petfocus.shieldaction`
  - App Group：`group.com.<你的域名>.petfocus.shared`
- Target 显示名建议：`PetFocusApp` / `DeviceActivityMonitor` / `ShieldConfiguration` / `ShieldAction`（与 PRD §8.2 四 Target 一致）。
- 需你提供：域名/前缀（例如 `cczij.dev` → `com.cczij.dev.petfocus`）。
- 决策后由我做的事：按确认后的命名生成工程配置。

### 5. Apple Team / entitlement 授权方式

- **默认建议：** 使用你现有的 iOS 开发签名身份（2026-08-10 基线已确认存在一个）；Family Controls entitlement 走 developer.apple.com 单独申请。
- **这是外部依赖最长路径，建议今天就启动申请**（PRD §8.7-8）：entitlement 获批前 P0 只能做工程搭建与模拟器验证，真机闭环必须 entitlement 落地。
- 需你执行：登录 Apple Developer 提交 Family Controls entitlement 申请；确认使用的 Team（个人/公司）。
- 我在此不做任何 Apple 账户操作。

### 6. P0 证据保存路径

- **默认建议：** `<项目路径>/P0Evidence/`
  - 子目录：`录屏/`、`矩阵/`（每项 PASS/FAIL 的 markdown 或 tsv 记录）、`截图/`
  - 命名：`<矩阵条目号>_<步骤简述>_<时间戳>`
- 每条证据按 PRD §8.5 字段记录：设备型号、iOS 版本、Xcode 版本、权限状态、步骤、预期、实际、PASS/FAIL、录屏文件名、已知限制。

### 7. 真机测试数据与账号

- **默认建议：** 真机测试使用你的个人测试 Apple ID 与测试数据（不涉及真实用户数据）；测试期间记录 iCloud/App 数据的边界（P1 无账号无云，测试期也不应产生云依赖）。
- 需你确认：测试机是否专用、测试期间是否接受 Screen Time 授权状态被反复切换。

### 8. 测试数据备份与恢复

- **默认建议：** P0 阶段不做数据备份（本地优先，无云）；删除数据验证以测试数据为准，不涉及真实用户。

## 四、P0 结论判定（照抄 PRD §11.1，防止口径漂移）

- **PASS：** 核心闭环逐项通过（§8.5 全部条目 + §8.4 不可接受项为零）；
- **FAIL：** 存在不可接受项（含重锁生效延迟超阈值）；
- **BLOCKED：** entitlement、签名或设备等外部条件尚未满足。

不得把 BLOCKED 写成 PASS，也不得以部分路径成功宣布技术绿灯。
