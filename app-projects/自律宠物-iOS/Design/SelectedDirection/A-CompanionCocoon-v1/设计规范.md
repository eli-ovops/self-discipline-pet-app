# 自律宠物 UI/UX 设计规范 v1

方向：A — 陪伴舱（Companion Cocoon）  
状态：已实施到 SwiftUI；待用户视觉验收  
日期：2026-08-11

## 1. 设计目标

让用户在准备专注、正在专注和短暂离开时，都感到宠物在安静陪伴，而不是被工具监督。

界面优先级始终为：当前关系状态 → 唯一目标 → 时间/保护状态 → 操作。

禁止把宠物变成新的干扰源；不增加信息流、签到、排行榜、商店、普通暂停、饥饿、惩罚、失败羞辱或重复互动入口。

## 2. 视觉语言

- 核心意象：宠物位于柔和椭圆光环中，光环代表“正在陪伴这件事”。
- 画面结构：大留白、单一焦点、低密度卡片、固定底部主要操作。
- 材质：暖色实底为主，只在目标、状态和输入区域使用轻量半透明表面。
- 角色：Milo 为橘猫、蓝色连帽衫；Max 为黑白哈士奇、鼠尾草绿色连帽衫。
- 角色完整性是硬门槛：主视觉必须完整展示双耳、额头、双眼、鼻口和下巴；宠物原始纵向资产使用等比适配，不得为了圆形构图裁切头脸。
- 状态徽标、进度、文案和装饰不得覆盖宠物头脸；空间不足时优先移动或缩小装饰，不缩减角色可见范围。
- 宠物主体必须使用透明背景独立资产，直接置于陪伴光环中；禁止为宠物添加矩形、圆角矩形、肖像卡片、白色边框或带底色的图片容器。
- 后续动作或角度可以变化，但必须延续同一角色的物种、脸型、毛色花纹、眼睛、服装和整体 3D 风格。
- 情绪：温暖、平静、诚实、鼓励；失败或结束只表达“我们下次继续”。

## 4. 字体

- 屏幕标题：系统 `.title.bold()`，`.fontDesign(.rounded)`。
- 情感状态标题：系统 `.title2.bold()`，`.fontDesign(.rounded)`。
- 正文：系统 `.body`；说明文字使用 `.secondary` 前景语义。
- 计时：系统 `.largeTitle` 或可缩放的等效层级，`.fontDesign(.rounded)` + `.monospacedDigit()`。
- 按钮：系统 `.headline`，不使用全大写。
- 中文和英文共用语义字号，不为视觉对齐写死字号。

AI 概念稿中出现的衬线标题不作为实现标准，以跨语言一致性和 Dynamic Type 为准。

## 5. 间距与形状

- 基础网格：8pt。
- 屏幕水平安全边距：24pt；紧凑宽度最低 20pt。
- 相邻小元素：8pt；组件内部：16pt；区块之间：24–32pt。
- 主要按钮高度：56pt；其他触控区域不得小于 44×44pt。
- 卡片圆角：24pt；小型输入/标签：14–16pt；光环使用连续曲线椭圆。
- 阴影只用于浮起的宠物光环和主要表面：低透明度、短距离，不堆叠多层阴影。

## 6. 五个核心页面

### 6.1 认领伙伴

- 标题：选择你的伙伴 / Choose your companion。
- Milo 和 Max 分别位于独立光环；同时只能选择一只。
- 显示性格短语，但不显示数值、稀有度或能力差异。
- 名称输入默认使用与性格匹配的名字，允许修改。
- 主要按钮：一起开始 / Start together。
- 明确说明只能认领一只；更换规则不在首次流程展开。

### 6.2 设置专注

- 顶部小光环显示当前宠物，作为关系连续性，不抢占输入空间。
- 唯一目标输入是页面第一任务。
- 选择专注时间与受限 App；只显示必要摘要，不在首页展开复杂统计。
- 主要按钮：开始专注 / Begin focus。

### 6.3 正在专注

- 宠物和蓝色进度光环占据视觉中心。
- 显示：陪伴状态、唯一目标、剩余时间、受保护 App 数量。
- 不提供普通暂停。
- 次级操作：这次先到这里 / End for now；二次确认后结束并使用积极文案。

### 6.4 必要使用

- 标题表达宠物仍在等待，而不是失望。
- 原目标持续可见。
- 显示通行窗口计时；提供预设原因和自定义原因。
- 主要按钮：返回专注 / Return to focus。
- 次级操作：这次先到这里 / End for now。
- 不使用红色警告，不出现“失败”“失去奖励”或“直接继续刷”的文案。

### 6.5 完成

- 光环从蓝色过渡为柔和杏色；宠物出现一次短完成动作。
- 文案：我们一起完成了 / You did it together。
- 展示本次目标和专注时长，记录为共同经历。
- 第一次普通完成不展示分享请求；纪念卡按 PRD 规定的节点另行触发。
- 主要按钮：完成 / Done。

## 7. 动效与反馈

- 宠物待机：3.2–4 秒轻微呼吸，缩放不超过 `1.015`。
- 专注光环：缓慢亮度呼吸；进度变化使用连续圆弧，不闪烁。
- 数字变化：使用 `.contentTransition(.numericText())`。
- 开始专注：光环由 0.92 缩放至 1.0，并淡入保护状态。
- 返回专注：必要使用表面向下收起，光环恢复蓝色；轻量成功触感。
- 完成：一次爪印或微光反馈，配合成功触感，不循环庆祝。
- 所有动效读取 Reduce Motion；开启时改用 150–200ms 淡入淡出。

## 8. 可访问性

- 支持 Dynamic Type；大字号时页面允许纵向滚动，按钮不被推出安全区。
- VoiceOver 顺序遵循：状态 → 目标 → 时间 → 保护状态 → 操作。
- 宠物图片的标签描述当前状态，例如“Milo 正在陪你完成数学第三章”，不描述衣服等无关细节。
- 选中状态同时使用勾选图标、边框和可访问性值，不只依靠颜色。
- Reduce Transparency 开启时，用不透明语义表面替代玻璃材质。
- 深色和亮色均需在真机验证文字、按钮和次级标签对比度。

## 9. 实施边界

本目录图片是构图和氛围参考，不是像素级工程规格。AI 稿中的第三方 App 图标、字体细节和角色姿势需要使用项目正式资产与系统允许的选择器替换。

本方向已按认领 → 设置 → 专注 → 必要使用 → 完成的顺序实施。亮色、深色与超大字体证据位于 `Design/ImplementationEvidence/A-CompanionCocoon-v1/`；Simulator 证据只证明界面和本地流程，不替代 Family Controls 真机结论。
