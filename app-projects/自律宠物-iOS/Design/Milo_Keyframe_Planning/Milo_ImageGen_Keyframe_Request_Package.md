# Milo ImageGen Keyframe Request Package

## Use boundary

This is a request package only. Do **not** run a generation tool from this file. Every request is an **image-edit** request using the stated real Approved Milo PNG and, after frame 01, the immediately prior approved keyframe as continuity input. Pure text-to-image is prohibited. The requested output is 1254×1254 RGBA with a transparent background; no runtime or Approved asset adoption is authorized.

## Global identity and coordinate lock

- Identity reference may only be a path under `Design/CharacterAssets/VintageShojo/Approved/Milo/` printed in the request.
- Fixed master canvas: 1254×1254 RGBA transparent; fixed camera, scale and `canvas_root=(627,1254)`; never alpha-bbox-center or crop.
- Keep Milo’s orange tabby face, forehead M/stripes, white muzzle/chest/paws, sage neckerchief, eye placement, hand-drawn linework/colored-pencil texture, lighting, and existing prop relationship.
- No global scale, float, bounce, fade-as-performance, camera motion, root drift, book/paw drift, opaque plate, chroma-key fringe, extra character, accessory, text, logo or identity change.
- Physical contact coordinates are `UNKNOWN` until artist markup. Preserve the named source contact relationship; do not invent a new one.
